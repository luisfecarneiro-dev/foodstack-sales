# SEO, GEO e Dados Estruturados

## Objetivo

Indexar a página para intenção de serviço relacionada a cardápio digital e sistemas de pedidos, sem conteúdo artificialmente repetitivo.

## Metadados base

Title:
`FoodStack | Cardápios digitais e sistemas de pedidos`

Description:
`Projetos de cardápio digital e sistemas de pedidos desenvolvidos sob medida para operações gastronômicas.`

## Conteúdo indexável

O texto que explica serviço, jornada, cases e processo deve existir em HTML. Não depender de canvas, vídeo ou animação para transmitir informação.

## Structured data

Pode usar:
- `WebSite`
- `Organization` somente com dados realmente confirmados
- `Service` com descrição do serviço

Não preencher:
- `address`;
- `foundingDate`;
- `priceRange`;
- `areaServed`;
- `sameAs`;
- CNPJ;
sem confirmação.

## GEO / motores de resposta

Criar texto factual e sem superlativos:
- o que é a FoodStack;
- quais tipos de fluxo podem ser desenvolvidos;
- quais cases são demonstrados;
- como entrar em contato.

`llms.txt` é opcional. Se usado, não deve listar rotas internas ou stack sensível.

## robots.txt

Somente rotas públicas. Como este projeto não possui admin, não há razão para publicar caminhos privados como regra de disallow — isso revelaria nomenclatura desnecessariamente.
