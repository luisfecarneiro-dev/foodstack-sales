## Requisitos

- MP4/H.264 como fallback universal.
- WebM opcional para reduzir peso.
- 1080p para desktop e versão vertical/móvel quando a captura justificar.
- Poster estático em AVIF/WebP.
- `preload="metadata"` ou `none`.
- Nunca autoplay com áudio.
- Carregar vídeos abaixo da dobra apenas quando próximos do viewport.
- Legendas descritivas quando houver narração.
- Não capturar tokens, rotas internas, dados pessoais, DevTools ou informações administrativas.
